# Dự án: Grade the Exams

1. Yêu cầu hệ thống
Để chạy được chương trình này, máy tính của bạn cần cài đặt:
* Python 3.x
* Thư viện Pandas (`pip install pandas`)
* Thư viện Numpy (`pip install numpy`)

2. Hướng dẫn khởi chạy chương trình:

Mở terminal/Cửa sổ lệnh: Di chuyển (cd) vào thư mục chứa dự án.

Chạy file python bằng câu lệnh:
python lastname_firstname_grade_the_exams.py

3. Sử dụng chương trình:

Hệ thống sẽ yêu cầu bạn nhập tên lớp học (Ví dụ: nhập class1 hoặc class2).

Chương trình tự động quét và phân tích dữ liệu. Nếu phát hiện dòng lỗi, hệ thống sẽ in cảnh báo lỗi đó ra màn hình và gắn nhãn lỗi khi xuất file kết quả.

Xem bảng phân tích thống kê toán học chi tiết tại màn hình hiển thị.

File điểm số tổng hợp dạng _grades.txt sẽ tự động được ghi/xuất ra cùng thư mục.

Sau khi hoàn tất một file, chương trình tiếp tục mời bạn nhập tệp khác. Để dừng chương trình, hãy gõ exit.
